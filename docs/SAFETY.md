# Lab safety and privacy

1. Use only systems and data you own or are explicitly authorized to use.
2. Keep the defined scope: do not turn a local exercise into public-target testing.
3. Use fictional fixtures for recordings and Git commits.
4. Treat automated output as evidence to review, not a final security conclusion.
5. Remove API keys, tokens, passwords, personal information, and production logs before every commit.

Reference: [OWASP Web Security Testing Guide](https://wstg.owasp.org/).
